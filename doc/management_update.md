# 玩具、测试集与嵌入式工具管理实现记录

## 本次范围

已实现玩具管理菜单（创建、编辑、禁用、环境接口、凭据环境变量引用、能力状态、显式连接检查）；公共/所属玩具专属测试集（创建空表、复制、启停、维护、选择多个执行）；嵌入式工具导入、严格解析、预览、保存备份、来源复用；精确工具名规则判定、规则分0/1、纯规则免裁判Key；快照、来源映射、跨测试集会话隔离与旧报告读取。

没有新增动态裁判模型、自定义用例类型、任意厂商协议、真实设备代理、硬件电量采集。原正式用例与工具描述没有自动迁移、删除或重归类，旧历史报告没有重判。

## 使用

1. 进入“玩具管理”，卡片列表支持搜索。点击右上“＋ 接入玩具”，弹窗只输入玩具名称和真实 Token（密码框）；Token 使用 Windows 当前用户 DPAPI 加密保存在 .runtime/credentials，普通档案仅保存不透明引用，OTA 发送解密后的真实 Token；点击卡片“配置详情”打开同样的两字段“编辑玩具”弹窗，仅修改名称和 Token，保留环境、能力及启用状态。编辑时不回显旧 Token，留空保留原值。新建时 Token 必填，可接受数字或其他实际 Token 内容。卡片“发起评测”仅跳转配置页面，不直接启动任务。统计来自真实档案与最近报告，无报告显示“—”，不使用原型示例数字。环境变量需由启动服务的进程继承；修改系统环境后通常需要重启服务。页面仅保存引用，不提供持久明文密钥管理。临时Token仍可在执行页输入。
2. 在接口与环境JSON配置环境名及字段：ota_url/ws_url/device_mac/client_id/device_name/board_ip/board_type/firmware_version/credential_ref/enabled。先校验配置，再按需明确点击联网检查。连接检查不是业务能力认证。
3. 声明能力 supported/unsupported/unverified；旧档案未声明继续兼容，保存后的能力需满足所选场景。长期记忆当前仍是已有同会话历史，不宣称跨会话持久记忆。
4. 进入“测试集与工具管理”，创建公共或当前玩具专属测试集，可复制或空表新增。选择维护测试集后使用原编辑器增删改用例，空集不可执行。公共修改影响所有复用者下一轮，独立复制不联动。
5. 在嵌入式工具页上传/粘贴定义，先预览再保存。默认使用共享工具文件，保存有备份；可选择复用已有玩具工具来源。远程发现只保留高级兼容入口。
6. 强制设备工具用例填写类型=MCP调用、是否工具调用=是、明确预期工具name。平台以调用name精确相等判定，不评价参数语义或回答质量。服务端天气场景填写否并用模型评价最终回答。否不意味着禁止服务端调用。
7. 执行页多选公共/专属集、选择环境、范围和凭据。多集按测试集+类别隔离会话，快照记录原表来源。单条阈值可用dataset_id区分同编号；原行号映射到执行行；歧义拒绝提交。
8. 结果页可查看测试集汇总、筛选及原行来源、工具规则分与执行异常。规则分不进入语言综合均值。工具命中但协议异常保留命中证据，业务统计列为未执行且任务执行失败。

## 兼容与边界

- 原CLI不传新增参数保持原默认；可用 --environment 和 --datasets。
- 事件可选environment/datasets；每日入口可选TOY_ENVIRONMENT/TOY_DATASETS。
- 新档案管理写入限制在项目内；旧显式绝对资产路径只读兼容，相对路径仍禁止越界。旧含明文token档案禁止管理保存以免密钥进入备份，需授权人员迁移环境变量引用。
- 工具定义不是硬件控制接口。程序接收tools/call并返回占位结果，只验证调用选择，不能验证真实电量。
- 当前旧工具文件含天气等历史定义，用户应依据嵌入式实际提供清单导入更新；程序未自动推断工具归属。
- 当前工作区无.git元数据，无法提供Git diff/提交回滚；所有正式资产维护继续走备份和冲突校验。

## 本地验证

环境：Windows / 项目独立Python 3.11.9（.runtime/venv-win）。原.venv为macOS复制环境，未覆盖。

命令：

```powershell
.runtime\venv-win\Scripts\python.exe scripts/check_environment.py
.runtime\venv-win\Scripts\python.exe -m pip check
.runtime\venv-win\Scripts\python.exe -m unittest discover -s tests -v
```

实际结果：环境与锁定依赖一致、pip check无冲突；67项测试，66通过，1跳过。日志：.runtime/management-verified-tests.log。跳过项为原有Windows TerminateProcess触发器停止测试，待目标Runner单独验收。

新增测试包括管理后端8项、嵌入式工具11项、管理集成8项；真实AppTest点击创建玩具、保存环境/能力、创建公共/专属测试集、工具预览保存，核对实际临时文件和备份；多集同类型同编号独立模拟socket、来源映射/Excel/统计；规则免Key、错误工具/能力阻断、单条阈值歧义与投影、回包异常统计。

测试使用临时资产、mock与本机协议服务，不调用真实外部裁判/设备，不发送通知。未将本地结果声明为新版本线上端到端验收。现有HTTP服务仍在127.0.0.1:8501；浏览器工具因当前可见会话限制无法本轮人工检查，页面交互由Streamlit AppTest验证。
